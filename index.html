Almost there — connect your Firebase project

Paste your new web-app config into firebaseConfig near the top of the script in this file, then reload.

  1. Authentication → enable Email/Password and Email link (passwordless sign-in) (the latter powers the 18+ media confirmation email).
  2. Firestore Database → create it (production mode).
  3. In Firestore, create the document config/invite with one string field code = your invite password. Nobody can read this from the browser — Firestore checks it server-side when someone registers.
  4. Create the document config/system (fields are created automatically the first time an admin opens Settings → Security, you can leave this empty).
  5. Firestore → Rules → paste the rules below and Publish.
  6. Register your own account, then in Firestore open users/<your uid> and change role to admin (lets you create/delete channels, moderate members, and manage server settings).
